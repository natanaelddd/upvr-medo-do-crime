# Medo do Crime · UPVR

Página de portfólio do projeto em realidade virtual **Medo do Crime**, feito pela UPVR para a pesquisa da USP de Ribeirão Preto (FMRP-USP, FAPESP 24/22996-5).

- `index.html`: a página inteira (HTML, CSS e JS num arquivo só)
- `frames/`: 120 quadros renderizados no Unreal Engine 5 para a rolagem do topo
- `img/`: capturas dos 6 estágios em cada ponto de vista (`pN-estagio-K.jpg`)

Publicada pelo GitHub Pages e mostrada no site da UPVR em `/portfolio/medo-do-crime`.
Para adicionar um ponto de vista: coloque `img/pN-estagio-1..6.jpg` e acrescente `{ n: N, nome: '...' }` à lista `POINTS` no `index.html`.
